# Howell Student AIDS Knowledge Data (Wide Form)

This data set, from Howell, measures students' knowledge at three time
points, in wide form.

## Usage

``` r
howell_aids_wide
```

## Format

A data frame with 4 observations and 4 variables.

|                                        |         |
|----------------------------------------|---------|
|                                        | student |
| student id                             | t1      |
| student AIDS knowledge score at time 1 | t2      |
| student AIDS knowledge score at time 2 | t3      |
| student AIDS knowledge score at time 3 |         |
