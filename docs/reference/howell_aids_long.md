# Howell Student AIDS Knowledge Data (Long Form)

This data set, from Howell, measures students' knowledge at three time
points, in long form.

## Usage

``` r
howell_aids_long
```

## Format

A data frame with 12 observations and 3 variables.

|                                                       |           |
|-------------------------------------------------------|-----------|
|                                                       | student   |
| student id                                            | time      |
| time point measured                                   | knowledge |
| student AIDS knowledge score (at various time points) |           |
